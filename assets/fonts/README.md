# Self-hosted font assets

The homepage uses only same-origin font files; no Google Fonts or Fontshare request is needed.

- `IBM-Plex-Sans-latin.woff2` — IBM Plex Sans variable weights 400–700
- `JetBrains-Mono-latin.woff2` — JetBrains Mono variable weights 400–700

Both families are distributed under the SIL Open Font License 1.1. The full license texts are included beside the font files as `IBM-Plex-Sans-OFL.txt` and `JetBrains-Mono-OFL.txt`.

Sources: https://fonts.google.com/specimen/IBM+Plex+Sans and https://fonts.google.com/specimen/JetBrains+Mono
