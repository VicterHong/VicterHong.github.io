Spareparts Inventory

Inventory & logistik untuk suku cadang alat berat

Sistem inventaris otomatis: FastAPI + PostgreSQL + Docker + n8n + bot Telegram. Menggantikan pencatatan manual dengan alur yang bisa diaudit.

Buka repo publik

Masalah yang diselesaikan

Pencatatan suku cadang secara manual mudah hilang dan sulit ditelusuri saat dibutuhkan. Saat alat berat berhenti karena satu komponen, waktu yang dihabiskan untuk mencari "apakah stoknya ada dan di mana" langsung menjadi biaya.

Yang bisa diperiksa publik

  • API FastAPI di atas PostgreSQL, dijalankan lewat Docker agar penyiapan konsisten.
  • n8n menghubungkan kejadian stok dengan notifikasi dan tindakan lanjutan.
  • Bot Telegram supaya tim bisa mengecek dan memperbarui stok tanpa membuka aplikasi lain.
